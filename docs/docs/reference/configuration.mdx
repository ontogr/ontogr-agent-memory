Settings classes use `pydantic-settings`. Each class reads the `.env` file in the
current directory and uses an environment prefix for its area. A server reads
its model and embedding settings from its
[server settings file](../guides/server-settings-file.mdx) instead of the
starter's environment. A role-specific setting replaces the global value for
that field, and an unset role field inherits the global value.

The table below is generated from the settings classes. Do not edit it by hand;
run `make docs-config` after changing a settings module.

## Nested settings

Nested settings join their names with `__`. For example, the maximum attempt
count of the FalkorDB resilience settings is
`MEMORY_FALKORDB_RESILIENCE__MAX_ATTEMPTS`. Set the whole object as a JSON value
for fields that accept a mapping, such as
`MEMORY_EMBEDDING_FASTEMBED_KWARGS='{"model_name":"...","threads":2}'`.

A blank value counts as unset for variables that declare it, including
`MEMORY_LLM_*` role overrides, `MEMORY_MCP_API_KEY`, and
`MEMORY_MCP_ONTOLOGY`. A blank role variable does not replace the global value.

## Variables outside settings

These names are read by plain code or by a caller and are not settings fields.

| Variable | Meaning |
| --- | --- |
| `MEMORY_DATA_DIR` | Directory for data, state, and server files. Overrides the platform default. |
| `FASTEMBED_CACHE_PATH` | Directory for local embedding model files. Overrides the cache subdirectory. |

## Store URLs and tenant rules

`MEMORY_GRAPH_URL` selects FalkorDB with `redis://` or `rediss://`, or Neo4j
with a Bolt or Neo4j scheme. `MEMORY_STATE_URL` selects SQLite with
`sqlite:///<absolute path>` or Postgres with `postgres://` or `postgresql://`.
Both schemes are accepted for Postgres. An in-memory state is not supported.
Credentials are secret values and are never printed by `ontogr-mem doctor`.

A non-loopback graph requires an explicit tenant other than `default`. Set
`MEMORY_MCP_TENANT`; a plugin with an empty `tenant` sends no header and reaches
the server's configured tenant. Percent-encode special characters in URL
credentials. See [Use FalkorDB](../guides/use-falkordb.mdx),
[Use Neo4j](../guides/use-neo4j.mdx), and
[Use Postgres for state](../guides/use-postgres-state.mdx).

# `ontogr_mem.errors` \{#ontogr_mem-errors}

Errors raised by the package.

**Classes:**

- [**AgentMemoryError**](AgentMemoryError.md) – Root of every error the package raises.
- [**AmbiguousNameError**](AmbiguousNameError.md) – A name resolves to more than one entity.
- [**MissingExtraError**](MissingExtraError.md) – One or more optional extras are not installed.
- [**StoreError**](StoreError.md) – Base class for every error a store raises.
- [**StoreInUseError**](StoreInUseError.md) – The local store is already owned by another process.

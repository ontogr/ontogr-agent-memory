---
title: OntoGr Agent Memory
description: Durable, traceable memory for AI agents.
---

OntoGr Agent Memory stores what an agent learned, where it learned it, and when
it was true. An agent writes source text and facts, then searches the tenant and
retrieves a budgeted context block with the evidence behind each fact.

- Facts keep the verbatim quote and the episode they came from. A hash-chained ledger records every temporal write.
- Each fact has a validity window and a record of when the system learned it, so a read can ask what was true on a date or what the system believed on that date.
- Rules, one optional model call per new fact with candidates, and a person's decision settle contradictions. A failed call leaves both facts live.
- The graph runs on FalkorDB or Neo4j, vectors live on the graph, and jobs and audit rows live in SQLite or Postgres. Each tenant is a separate partition.

Install the package with all backends:

```bash
uv add "ontogr-mem[local,neo4j,postgres]"
```
